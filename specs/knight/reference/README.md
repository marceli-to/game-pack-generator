# Knight reference

`turnaround.png`: skeleton knight, front / side / back turnaround plus sword, painted chibi style, by Marcel
(own work, released with this repo).

- Reference of the `painted` style (styles/painted/STYLE.md) and the painted-surface spike (auto paint vs
  projection, 2026-11-15).
- Calibration source of the `chibi` proportion template (styles/painted/STYLE.md §7a). Measured with the
  skull top at y=215 px (estimated, inside the helmet) and the floor at y=893 px (678 px = 1.20 m,
  1 px ≈ 1.77 mm). View centres for `add_reference`: front x=301 (range 30–560), side x=715 (560–880),
  back x=1120 (880–1345). Arms drawn ≈ 67° down from the T-pose.
